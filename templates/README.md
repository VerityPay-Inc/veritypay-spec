# Templates (index)

This directory is an index. VerityPay specification templates live in two locations, matching how standards bodies separate **change proposals** from **stable specification documents**.

---

## Documentation hierarchy

**You are here: Index only** — see [`../docs/README.md`](../docs/README.md#documentation-pyramid) for the full pyramid.

| Template | Location |
|----------|----------|
| Specification header (required on all specs) | [`../docs/templates/snippets/SPEC_HEADER.md`](../docs/templates/snippets/SPEC_HEADER.md) |
| Constitutional navigation | [`../docs/templates/snippets/CONSTITUTIONAL_NAV.md`](../docs/templates/snippets/CONSTITUTIONAL_NAV.md) |
| Stable specifications | [`../docs/templates/SPEC_TEMPLATE.md`](../docs/templates/SPEC_TEMPLATE.md) |
| RFC proposals | [`../rfcs/templates/RFC_TEMPLATE.md`](../rfcs/templates/RFC_TEMPLATE.md) |

---

## Purpose

Point contributors to the correct template for the document they are authoring. Using the wrong template slows review and blurs the line between draft proposals and accepted specification text.
