# Templates (index)

This directory is an index. VerityPay specification templates live in two locations, matching how standards bodies separate **change proposals** from **stable specification documents**.

---

## Purpose

Point contributors to the correct template for the document they are authoring. Using the wrong template slows review and blurs the line between draft proposals and accepted specification text.

---

## Audience

| Reader | Start here |
|--------|------------|
| RFC authors | [`../rfcs/templates/RFC_TEMPLATE.md`](../rfcs/templates/RFC_TEMPLATE.md) |

**In scope**

**Out of scope**

- Completed RFCs, specifications, or decision records
