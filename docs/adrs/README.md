# Architecture Decision Records

Platform and specification engineering decision records for the VerityPay ecosystem. ADRs in this directory capture **cross-repository** and **specification-repository** engineering policy—they do **not** define protocol behavior (that remains in accepted RFCs and published Editions).

Repository-local ADRs live in sibling repositories:

| Repository | ADR index |
|------------|-----------|
| [veritypay-tooling](https://github.com/VerityPay-Inc/veritypay-tooling/blob/main/docs/adrs/README.md) | Validation and specification model decisions |
| [veritypay-reference](https://github.com/VerityPay-Inc/veritypay-reference/blob/main/docs/adrs/README.md) | Reference interpreter decisions |
| [veritypay-conformance](https://github.com/VerityPay-Inc/veritypay-conformance/blob/main/docs/adrs/README.md) | Conformance harness decisions |

Process aligns with [ADR Guide](../05-governance/ADR_GUIDE.md).

| ADR | Title | Status |
|-----|-------|--------|
| [0008-platform-release-policy.md](0008-platform-release-policy.md) | Platform Release Policy | Accepted |
